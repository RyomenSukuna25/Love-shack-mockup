# The Love Shack · Aruba

A luxury Caribbean villa web experience inspired by Villa Aurelia, featuring:
- Full responsive website (Home, Features, Amenities, Contact)
- Interactive dual-month check-in / check-out booking calendar
- Mandatory 10-minute countdown demonstration hold timer
- Six-step luxury booking wizard with accurate monetary calculations
- Demonstration PDF receipt generator & .ics calendar event download
- Branded email preview and resend simulation
- 32-photo editorial gallery & fullscreen accessible lightbox
- Sticky villa storytelling and horizontal scroll gallery
- Contextual custom cursor and magnetic micro-interactions

## Running Locally
Open `index.html` or `love-shack-aruba.html` directly in any modern browser, or run a local web server:
```bash
npx serve .
# or
python3 -m http.server 3000
```
